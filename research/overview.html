Research overview

Why model the whole visual field?

Central refraction is one useful description of vision. Optinex investigates how field position, ocular geometry, gaze, light, and visual function can be measured together and tested as a reproducible research system.

Research-stage platform. The following is a research program, not a diagnostic or commercial product description.

01 / Known and open

Start with what can be measured, then name the gap.

Known starting points

Refractive state, retinal and corneal geometry, pupil response, contrast sensitivity, and behavioral outcomes can each be studied under defined conditions.

Open questions

Their field-dependent relationship, repeatability across instruments, external validity, and usefulness for an adaptive optical system still require explicit tests.

02 / Pipeline

One loop, four accountable stages.

01 / INPUT

Measure

Document ocular, optical, and visual-function inputs and their conditions.

Output: traceable observations
02 / COMPUTE

Model

Represent field-dependent geometry and optical states with stated assumptions.

Output: reproducible model
03 / PROTOTYPE

Augment

Test an optical component only with safety, usability, and comparison conditions.

Output: prototype test result
04 / CHECK

Learn

Compare repeatability, uncertainty, and alternative explanations before updating.

Output: next falsification test

03 / Programs

Four programs, each with a question and a way to fail.

PROGRAM 01Wide-field Eye Modeling

How should the retinal and optical state of the whole visual field be modeled, not only central vision?

Existing

Program-level public assets: none currently mapped. Source review is pending.

Missing

External validation data and versioned public model exports are still required.

Next test

Test whether an independent device or investigator can reproduce similar peripheral model outputs from the same inputs.

PROGRAM 02Visual Neuroperformance

How do contrast sensitivity, pupil response, and binocular function explain real visual performance?

Existing

Program-level public assets: none currently mapped. Source review is pending.

Missing

Publicly reviewable sample, stimulus, and analysis-pipeline documentation is needed.

Next test

Test whether effect direction and uncertainty remain stable in repeated measurements under the same protocol.

PROGRAM 03Adaptive Optical Systems

What optical systems or prototypes can realize the measured field model?

Existing

Program-level public assets: none currently mapped. Prototype claims require separate review.

Missing

Public prototype specifications and safety-review scope are required.

Next test

Separate device effects from learning or fatigue effects in pre/post prototype testing.

PROGRAM 04Longitudinal Eye Intelligence

How should changing ocular and visual function be tracked and predicted over time?

Existing

Program-level public assets: none currently mapped. Longitudinal evidence is not asserted here.

Missing

Longitudinal data and external validation cohorts are required.

Next test

Test whether baseline measurements predict follow-up changes within a predefined error range.

04 / Maturity

Current maturity is a validation backlog.

The four programs define research direction. They do not establish diagnostic accuracy, clinical readiness, product availability, or a completed adaptive system. The next gate is source review, followed by reproducible measurement and independent falsification.
