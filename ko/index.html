연구 단계 시각공학 플랫폼

교정은 중심시에서 멈춥니다.
우리는 시야 전체를 모델링합니다.

Optinex는 눈을 측정하고, 시야 위치에 따른 광학 상태를 모델링하며, 적응형 시스템이 시각 수행을 어떻게 지원할 수 있는지 검증합니다.

현재 상용 의료 제품은 없습니다.

01 / 패러다임

시각은 하나의 처방이 아니라 하나의 장입니다.

일반 처방이 설명하는 것

정해진 검사 조건에서 측정한 중심 굴절 상태입니다.

앞으로 검증할 것

시야 위치, 안구 기하, 시선, 조도, 시각 기능이 개인별로 어떻게 상호작용하는지입니다.

기존 교정이 모든 사람에게 부족하다는 주장이 아니라, 검증할 연구 질문입니다.

02 / 플랫폼 루프

측정 → 모델 → 증강 → 학습

01

측정

문서화된 조건에서 안구·광학·시각 기능 입력을 수집합니다.

openaxis-biometer · rtAR · pupil_dynamics
02

모델

재현 가능한 가정으로 시야별 기하와 광학 상태를 표현합니다.

ret_prof · Panretinal-Refractometer
03

증강

안전성과 사용성 검토를 포함해 가변 광학 부품을 시제품으로 시험합니다.

shutter_glasses · Tuning-Lens Firmware
04

학습

모델을 갱신하기 전에 결과, 불확실성, 반복성을 비교합니다.

GaborPatch · bino_rehab

03 / 연구 프로그램

네 가지 질문이 연구를 구성합니다.

  1. Wide-field Eye Modeling시야 전체의 광학 상태를 어떻게 표현할 것인가?
  2. Visual Neuroperformance시각 기능 측정은 행동과 어떻게 연결되는가?
  3. Adaptive Optical Systems어떤 광학 시제품으로 시야 모델을 시험할 수 있는가?
  4. Longitudinal Eye Intelligence시간에 따른 측정 변화를 어떻게 추적할 것인가?

04 / 연구 계보

측정에서 반증 가능한 시스템으로 확장합니다.
