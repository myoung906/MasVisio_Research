ENKO

Research-stage visual engineering

Correction stops at central vision.
We model the whole visual field.

Optinex measures the eye, models field-dependent optical states, and tests how adaptive systems might support visual performance.

No commercial medical product is currently available.

01 / Paradigm

Vision is a field, not a single prescription.

What a standard prescription describes

A compact central refractive state, measured under a defined examination condition.

What remains to be tested

How field position, ocular geometry, gaze, light, and visual function interact for an individual.

This is a research question, not a claim that existing correction is inadequate for every person.

02 / Platform loop

Measure → Model → Augment → Learn

01

Measure

Collect ocular, optical, and visual-function inputs under documented conditions.

openaxis-biometer · rtAR · pupil_dynamics
02

Model

Represent field-dependent geometry and optical states with reproducible assumptions.

ret_prof · Panretinal-Refractometer
03

Augment

04

Learn

03 / Programs
